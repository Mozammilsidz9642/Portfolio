Grinspire Welfare Foundation

A full-stack NGO website for legal aid, literacy support, and healthcare outreach, built with a modern React and Node.js monorepo setup.

Overview

Grinspire Welfare Foundation is a community-focused website for a nonprofit organization working across human rights and legal aid, literacy and education, and healthcare support. The project presents the foundation's services, donation flow, membership path, contact options, and impact-focused storytelling in a clean, responsive interface.

Highlights

  • Separate client and server apps in a workspace-style structure
  • Responsive NGO landing pages for services, about, gallery, membership, donate, and contact
  • Clean UI for trust-building storytelling and community impact
  • Backend support with Express and CORS middleware
  • Built for a production-style deployment workflow
