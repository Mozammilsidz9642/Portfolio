Project Detail

Cinematic Interactive Web Experience

A multi-page animated React app with cinematic transitions, passcode-gated access, interactive storytelling, and dynamic route-based audio.

Overview

Built from scratch as a fully custom interactive web application across 5+ routes. The experience includes a passcode entry flow, smooth-scroll physics, animated page transitions, particle and confetti effects, a cake-candle interaction, a photo-timeline storytelling module, and a global audio system that swaps background music per route while preserving playback state.

Technology Badges

React.jsTypeScriptViteTailwind CSSFramer MotionGSAPReact RouterUI/UX DesignWeb PerformanceGit

Highlights

  • Cinematic page transitions and smooth-scroll physics
  • Passcode-gated entry flow across a multi-page experience
  • Custom particle, confetti, and cake-candle interactions
  • Photo-timeline storytelling module with dynamic content
  • Context-driven global audio system with per-route music
  • Route-based lazy loading and custom Vite image loading plugin
